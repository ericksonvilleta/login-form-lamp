# Login Form Lamp

An interactive login interface featuring a glowing vector lamp with a pull-cord toggle switch, built with HTML, CSS, and JavaScript (powered by GSAP).

---

## Features

* **Interactive Pull-Cord:** Click and drag or pull the cord to toggle the lamp state on and off.
* **Smooth Animations:** Integrated with GSAP for fluid transitions and interactive drag physics.
* **Dynamic Lighting:** Illuminates the surrounding background and activates the login container when switched on.
* **Modern Glassmorphism:** Sleek, responsive login card design with custom input styling.
* **Custom Silhouette SVG:** Styled with a classic trapezoidal shade, slender neck connector, and bulbous ginger jar base matching custom vector design guidelines.

---

## Project Structure

```text
├── index.html    # Main HTML structure containing the vector lamp and login form
├── style.css     # Stylesheet for layout, theme variables, and component styling
└── script.js     # JavaScript logic handling the cord-pull interaction and toggle states
```

---

## Getting Started

1. Clone or download this repository to your local machine.
2. Ensure all files (`index.html`, `style.css`, and `script.js`) are in the same directory.
3. Open `index.html` in any modern web browser or run it via a local development server (such as Live Server in VS Code).

---

## Technologies Used

* **HTML5** (Semantic structure & Inline Custom SVG)
* **CSS3** (Variables, Flexbox, Glassmorphism effects)
* **JavaScript** (DOM manipulation & event handling)
* **GSAP (GreenSock Animation Platform)** & **Draggable Plugin** (for interactive animations and cord physics)
